시작하기

이것은 시스템이 정상 작동하는지 확인하기 위한 샘플 강의입니다. 실제 운영 시에는 이 자리에 Emacs에서 export한 readthedoc 테마의 HTML이나 Claude가 생성한 동적 HTML이 들어갑니다.

이 자료의 역할

메인 셸의 사이드바, iframe 임베딩, 검색, 다크모드 토글, 키보드 단축키가 정상 동작하는지 확인하는 용도입니다.

샘플 코드

def hello():
    print("Hello, lectures!")

hello()
실제 org export 자료는 자체 사이드바와 코드 copy 버튼을 가지고 있을 겁니다. iframe 방식이라 그 기능들은 그대로 보존됩니다.
