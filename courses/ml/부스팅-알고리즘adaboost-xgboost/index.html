  1. AdaBoost
  2. XGBoost

두 알고리즘 모두 "약한 모델 여러 개를 합쳐서 강한 모델을 만든다"는 생각에서 출발한다. 각 알고리즘을 설명한 뒤, 같은 실무 데이터에 적용해 본다.

1부: AdaBoost

1-1. 이 이론이 필요한 배경

결정 트리 하나로 데이터를 분류한다고 하자. 깊이가 1인 트리는 질문을 딱 한 번만 한다. 예를 들어 "반지름이 15보다 큰가?" 하나로 끝난다. 이런 트리를 결정 그루터기(decision stump) 라고 부른다.

그루터기 하나는 성능이 약하다. 동전 던지기보다 조금 나은 정도다. 이런 약한 모델을 약한 학습기(weak learner) 라고 한다.

여기서 질문이 생긴다.

약한 모델을 여러 개 모으면 강한 모델이 될 수 있을까?

AdaBoost의 답은 "그렇다"이다. 단, 그냥 모으는 게 아니라 앞 모델이 틀린 데이터에 집중하도록 다음 모델을 만든다.

1-2. 기본 개념

핵심 아이디어는 세 가지다.

  1. 데이터마다 가중치 를 준다. 처음에는 모두 똑같다.
  2. 약한 학습기를 하나 만든 뒤, 그 학습기가 틀린 데이터의 가중치를 키운다. 다음 학습기는 어려운 데이터를 더 신경 쓴다.
  3. 학습기마다 발언권(weight) 을 다르게 준다. 잘 맞히는 학습기일수록 최종 투표에서 발언권이 크다.

비유하자면, 시험 문제를 여러 번 푸는 것과 같다. 틀린 문제에 표시해 두고 다음에 그 문제를 더 집중해서 푼다.

1-3. 알고리즘 설명

데이터가 \( N \)개 있고, 라벨은 \( y_i \in \{-1, +1\} \)이다.

1단계. 가중치 초기화

모든 데이터의 가중치를 똑같이 둔다.

\[ w_i = \frac{1}{N}, \quad i = 1, 2, \dots, N \]

2단계. 약한 학습기 학습과 오차 계산

\( t \)번째 학습기 \( h_t \)를 만든다. 이 학습기의 오차는 틀린 데이터의 가중치 합 이다.

\[ \varepsilon_t = \frac{\sum_{i : h_t(x_i) \neq y_i} w_i}{\sum_{i} w_i} \]

3단계. 학습기 발언권 계산

오차가 작을수록 발언권 \( \alpha_t \)가 커진다.

\[ \alpha_t = \frac{1}{2} \ln \left( \frac{1 - \varepsilon_t}{\varepsilon_t} \right) \]

  • \( \varepsilon_t \)가 0에 가까우면(잘 맞힘) → \( \alpha_t \)는 큰 양수
  • \( \varepsilon_t = 0.5 \)면(찍기 수준) → \( \alpha_t = 0 \) (발언권 없음)

4단계. 데이터 가중치 갱신

\[ w_i \leftarrow w_i \cdot e^{-\alpha_t y_i h_t(x_i)} \]

여기서 \( y_i h_t(x_i) \)의 부호를 보자.

  • 맞힌 데이터: \( y_i h_t(x_i) = +1 \) → 가중치가 줄어든다
  • 틀린 데이터: \( y_i h_t(x_i) = -1 \) → 가중치가 커진다

갱신 후 전체 가중치 합이 1이 되도록 다시 정규화한다.

5단계. 최종 예측

학습기들의 예측을 발언권으로 가중 투표한다.

\[ H(x) = \text{sign}\left( \sum_{t=1}^{T} \alpha_t h_t(x) \right) \]

1-5. 간단 예제

직접 그루터기를 만들지 않고, scikit-learn으로 동작을 본다. 여기서는 개념 확인용 가상 데이터를 쓴다. 

from sklearn.datasets import make_classification
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import AdaBoostClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 1. 가상 데이터
X, y = make_classification(
    n_samples=400, n_features=2, n_redundant=0,
    n_clusters_per_class=1, random_state=42
)

# 2. 분리
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 3. 약한 학습기 = 깊이 1 트리
stump = DecisionTreeClassifier(max_depth=1)

# 4. AdaBoost 구성
ada = AdaBoostClassifier(
    estimator=stump, n_estimators=50,
    learning_rate=1.0, random_state=42
)

# 5. 학습과 평가
ada.fit(X_tr, y_tr)
pred = ada.predict(X_te)
print("정확도:", round(accuracy_score(y_te, pred), 3))

실행 단계 설명

  1. make_classification 으로 2차원 가상 데이터를 만든다.
  2. 학습 70%, 평가 30%로 나눈다.
  3. 깊이 1짜리 트리를 약한 학습기로 정한다.
  4. AdaBoostClassifier 가 이 그루터기 50개를 순서대로 만든다.
  5. 평가 데이터로 정확도를 잰다.

주요 함수와 인자

  • AdaBoostClassifier
    • estimator : 약한 학습기. 보통 깊이 1 트리.
    • n_estimators : 학습기 개수.
    • learning_rate : 각 학습기의 발언권을 줄이는 정도.
  • fit(X, y) : 학습.
  • predict(X) : 예측.

1-6. 고찰: 장점과 단점, 개선 방향

장점

  • 구조가 단순하고 이해하기 쉽다.
  • 약한 학습기만 있으면 성능이 좋아진다.
  • 튜닝할 인자가 적다.

단점

  • 이상치와 잡음에 약하다. 틀린 데이터의 가중치를 계속 키우는데, 잡음은 원래 맞히기 어려워서 거기에 과하게 집중한다.
  • 순차 학습이라 병렬 처리가 어렵다.

개선 방향

  • 가중치를 키우는 방식 대신 잔차 를 직접 학습하는 방법으로 바꾼다. 이게 그래디언트 부스팅이고 XGBoost로 이어진다.

2부: XGBoost

2-1. 이 이론이 필요한 배경

AdaBoost는 "틀린 데이터에 가중치를 더 준다"는 방식이었다. 그래디언트 부스팅은 생각을 바꾼다.

틀린 만큼의 "오차(잔차)"를 다음 트리가 직접 학습하면 어떨까?

예를 들어 정답이 100인데 70이라고 예측했다면 오차는 30이다. 다음 트리는 이 30을 맞히려 한다. 이렇게 오차를 줄여 나간다.

XGBoost는 이 그래디언트 부스팅을 빠르고 정확하게 만든 구현이다. 캐글 대회에서 자주 우승하며 유명해졌다.

2-2. 기본 개념

핵심은 세 가지다.

  1. 잔차 학습 : 새 트리는 지금까지의 오차를 학습한다.
  2. 이계 도함수 사용 : 오차를 더 정확히 근사하려고 미분을 두 번 쓴다. (기울기와 곡률을 같이 본다)
  3. 규제(regularization) : 트리가 너무 복잡해지지 않도록 벌점을 준다. 과적합을 막는다.

2-3. 알고리즘 설명

예측의 형태

XGBoost는 트리 \( K \)개의 예측을 더한다.

\[ \hat{y}_i = \sum_{k=1}^{K} f_k(x_i) \]

목적 함수

\[ \text{Obj} = \sum_{i=1}^{N} L(y_i, \hat{y}_i) + \sum_{k=1}^{K} \Omega(f_k) \]

  • \( L \) : 손실 함수. 예측이 틀린 정도.
  • \( \Omega \) : 규제 항. 트리 복잡도에 주는 벌점.

규제 항은 보통 이렇게 쓴다.

\[ \Omega(f) = \gamma T + \frac{1}{2}\lambda \sum_{j=1}^{T} w_j^2 \]

  • \( T \) : 잎(leaf)의 개수
  • \( w_j \) : \( j \)번째 잎의 출력값
  • \( \gamma, \lambda \) : 벌점 세기

이계 테일러 근사

새 트리 \( f_t \)를 더할 때 손실을 근사한다.

\[ \text{Obj}^{(t)} \approx \sum_{i=1}^{N} \left[ g_i f_t(x_i) + \frac{1}{2} h_i f_t(x_i)^2 \right] + \Omega(f_t) \]

  • \( g_i \) : 손실의 일계 도함수 (기울기)
  • \( h_i \) : 손실의 이계 도함수 (곡률)

잎의 최적 출력값

\[ w_j^* = - \frac{\sum_{i \in I_j} g_i}{\sum_{i \in I_j} h_i + \lambda} \]

\( I_j \)는 \( j \)번째 잎에 속한 데이터들이다.

분할 이득(gain)

\[ \text{Gain} = \frac{1}{2}\left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma \]

이득이 \( \gamma \)보다 크면 가지를 나누고, 작으면 나누지 않는다.

2-5. 간단 예제

import xgboost as xgb
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X2, y2 = make_classification(
    n_samples=600, n_features=10, n_informative=5, random_state=42
)
X2_tr, X2_te, y2_tr, y2_te = train_test_split(
    X2, y2, test_size=0.3, random_state=42
)

model = xgb.XGBClassifier(
    n_estimators=200, max_depth=3, learning_rate=0.1,
    reg_lambda=1.0, gamma=0.0, random_state=42
)
model.fit(X2_tr, y2_tr)
print("정확도:", round(accuracy_score(y2_te, model.predict(X2_te)), 3))

실행 단계 설명

  1. 특성 10개짜리 가상 데이터를 만든다.
  2. 학습 70%, 평가 30%로 나눈다.
  3. XGBClassifier 로 트리 200개, 깊이 3 모델을 만든다.
  4. fit 으로 잔차를 줄이며 학습한다.
  5. 정확도를 잰다.

주요 함수와 인자

  • XGBClassifier
    • n_estimators : 트리 개수.
    • max_depth : 트리 깊이.
    • learning_rate : 각 트리의 반영 비율.
    • reg_lambda : 수식의 \( \lambda \). 잎 출력값 벌점.
    • gamma : 수식의 \( \gamma \). 분할 최소 이득.
  • fit , predict , predict_proba : 학습과 예측.

2-6. 고찰: 장점과 단점, 개선 방향

장점

  • 정확도가 높다. 표 형태 데이터에 특히 강하다.
  • 규제 항이 있어 과적합에 강하다.
  • 결측치를 자동 처리한다.
  • 병렬 처리로 빠르다.

단점

  • 인자가 많아 튜닝이 까다롭다.
  • 트리를 깊게 키우면 과적합한다.
  • 해석이 어렵다.

개선 방향

  • learning_rate 를 작게, n_estimators 를 크게 두고 조기 종료를 쓴다.
  • LightGBM, CatBoost 같은 변형을 쓴다.

3-2. 마무리 고찰

두 알고리즘을 한눈에 정리한다.

항목   XGBoost
학습 방식 틀린 데이터 가중치 ↑ 잔차를 직접 학습
수학 도구 가중치, 발언권 일계·이계 도함수, 규제
잡음 내성 약하다 상대적으로 강하다
속도 순차적 병렬 처리로 빠르다
튜닝 쉽다(인자 적음) 까다롭다(인자 많음)

실무 선택 기준

  • 데이터가 작고 깔끔하면 AdaBoost로 시작해도 좋다.
  • 표 형태 데이터에서 높은 정확도가 필요하면 XGBoost를 쓴다.
  • XGBoost는 조기 종료와 교차검증으로 과적합을 막는다.
